# 移动端响应式架构补充方案

本文件是 `ARCHITECTURE-UPGRADE.md` 的移动端补充，不改变既有领域模型、权限、数据源、接口契约和部署架构。

## 适配基线

- 主验收机型：华为 Pura 80，按约 412 CSS 像素宽的浏览器视口验证。
- 兼容范围：360–767 CSS 像素；768 像素及以上继续使用桌面布局。
- 不建立独立手机版业务代码，所有终端共用 React 页面、React Query 数据层和后端 API。

## 全局布局约定

- 顶部导航在手机端压缩为 56px 标题栏，保留页面标题、通知和账户入口。
- 左侧菜单改为带遮罩的抽屉，选择最终菜单后自动收起，权限和菜单层级与桌面端一致。
- 主内容使用安全区内边距，页面本身不得产生横向溢出。
- 指标卡与工具栏通过 `mobile-summary-grid`、`mobile-page-toolbar` 重排为单列或双列。

## 筛选、弹窗与表格

- 业务筛选器使用 `mobile-filter-row`：日期范围占整行，其余筛选两列排列，全部条件均可直接触达。
- 日期范围仍是一个选择器；弹层纵向展示起止月份，底部保留全部、上个月、今日、本周、本月和今年等快捷项。
- 弹窗最大宽高受手机安全可视区约束，正文独立滚动；输入字号不低于 16px，防止聚焦自动缩放。
- 高信息密度业务表格不删除字段。手机端解除占屏过大的桌面冻结列，在 `mobile-business-table` 容器内提供触控横向滚动。

## 页面验收清单

- 首页：KPI、数据趋势和待办中心无横向溢出。
- 客户与订单：搜索、操作、日期及所有筛选可用；数据表可横向查看完整字段。
- 排期与预约：周历可触控横移，预约列表指标卡和筛选清晰可读，弹窗不超出屏幕。
- 技师与工资：摘要卡、工具栏适配；复杂表格完整保留并在容器内横移。
- 系统设置：搜索、账号操作和权限说明在手机端可用。

以后继续优化时，应先复用以上全局类，再增加页面级例外；移动端改动不得绕开服务端权限、审计凭证或既有 API。
