## 2. 部署架构

```text
浏览器
  -> HTTPS / Nginx 前端容器
  -> /api 反向代理
  -> Node.js 后端容器
     -> 阿里云 RDS MySQL（业务数据、凭证、审计、迁移版本）
     -> 阿里云 OSS（业务附件）
     -> 企业微信应用接口（预约通知）
```

- ECS 承载前端、后端及发布目录，保留同机无关的 SearXNG 服务。
- RDS 是生产业务唯一结构化数据源；空库启动时先加载基础结构，再按顺序执行迁移。
- OSS 是生产附件存储；上传接口已验证返回 `storage: oss`。
- Redis/Tair 当前未启用，系统不依赖其完成核心业务。
